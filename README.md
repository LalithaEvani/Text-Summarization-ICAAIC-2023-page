# Text Summarization of Medical Documents — Project Page

Project page for the ICAAIC 2023 paper *"Text Summarization of Medical
Documents using Abstractive Techniques"* (Evani Lalitha, Esikela Venkata Sai
Deepak, Kasarapu Ramani, M. Hima Bindu, Dudekula Shahida, Diguri
Shaikshavali — Sree Vidyanikethan Engineering College).

- **Live page:** https://LalithaEvani.github.io/Text-Summarization-ICAAIC-2023-page/
- **Paper (IEEE Xplore):** https://ieeexplore.ieee.org/abstract/document/10140885/

No public code repo for this one, so there's no Code button — only the paper
link. No self-hosted PDF (IEEE conference paper, copyright not confirmed
open); links out to IEEE Xplore instead.

## Editing

Everything is in `index.html` — no build step.

## Deploying changes

```
git add -A && git commit -m "..." && git push
```
GitHub Pages serves straight from `main` — no separate build/deploy workflow.
